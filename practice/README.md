# Practice

문제 번호 없이 연습용으로 작성한 코드들. 유형별로 묶었습니다.

| 폴더 | 내용 |
|---|---|
| `backtracking/` | 백트래킹 연습 시리즈 (`back1`~`back8`), N-Queen, 순열/조합/부분집합 |
| `graph/` | DFS 기초, 다익스트라 |
| `simulation/` | 배열 회전, 로봇청소기, 방향 전환 시뮬레이션 |
| `array/` | 2차원 배열 다루기 — 달팽이, 파스칼 삼각형, 스도쿠 검증, Ladder 등 |

`array/` 안의 일부는 SWEA 문제로 보이지만 문제 번호를 확인하지 못해 원래 파일명 그대로 두었습니다.
